## Research questions

- How can project websites stay maintainable when the underlying static site generator changes?
- Which parts of a research website are genuinely project-specific, and which parts are boilerplate?
- Can publications be authored once and rendered consistently for humans and machines?

## Planned outcomes

- A documented theme with a small configuration surface.
- A starter site that can be copied or scaffolded for a new project.
- A migration path for the existing TOP, SNIK, HITO and ANNO websites.
